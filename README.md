# 📱 Mobile & Accessories E-Commerce System

An integrated e-commerce platform built with **Laravel 11** for selling mobile phones, accessories, and covers. The system features a modern user interface, advanced product management, and a complete checkout workflow.

---

## 🚀 Key Features

### 🛒 Frontend (User Side)
- **Product Catalog:** Browse mobiles, covers, and accessories by category.
- **Advanced Search:** Real-time search by product name and description.
- **Shopping Cart:** Manage products, quantities, and price calculations.
- **Checkout System:** Integrated delivery system to collect address and contact details.
- **Installment Plans:** Information about installment options with interest rates.

### ⚙️ Backend (Admin Side)
- **Dashboard:** Overview of total stock and sales statistics.
- **Product Management:** Full CRUD (Create, Read, Update, Delete) for products and categories.
- **Bulk Actions:** Ability to delete or update multiple products/plans at once.
- **Soft Deletes:** Safety feature to recover accidentally deleted items.
- **Data Export/Import:** Export products and plans to Excel/CSV files.

---

## 🛠️ Tech Stack

- **Backend:** [Laravel 11](https://laravel.com/) (PHP)
- **Frontend:** Blade Templates, Bootstrap 5, FontAwesome, Bootstrap Icons.
- **Database:** MySQL.
- **Tools:** Laravel Excel (Maatwebsite), Composer, Git/GitHub.
